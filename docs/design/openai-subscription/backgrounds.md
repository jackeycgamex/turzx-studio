# OpenAI 订阅背景

控制台的 OpenAI 订阅 → 背景提供空背景、IT · 冰蓝电路、动漫 · 海滨晨光、OpenAI · 龙娘四个选项，首次使用默认空背景。背景、透明度、屏幕方向、当前场景页面和发送帧率每次修改后自动保存到本地 `runtime/display-preferences.json`，服务重启后恢复上次设置。自动轮播换页时也保存当前场景。该文件另保存 `resume_streaming` 恢复投屏标志，不包含订阅数据，也不修改设备固件设置。

成功开始投屏后记录恢复标志，关闭服务时的内部资源清理不清除它；手动停止投屏才清除。启动时实际连接状态先保持断开，在 HTTP 服务可用时尝试一次恢复。连接失败不循环重试，控制台可查看错误并手动开始；恢复标志保留，供下次启动再次尝试。此行为不涉及 Windows 开机自启动。

写入使用同目录临时文件与原子替换，成功保存后才更新共享状态；文件缺失、损坏或字段无效时按字段回退默认值。总览顺序为 Work / Codex 周额度、图像生成、深度研究；竖屏保持同样的上下顺序。

六张背景保存在 `web/assets/subscription/`，均由内置 imagegen 于 2026-11-13 为本项目生成。龙娘为 OpenAI 灵感的原创非官方拟人形象。没有使用外部图库素材。

横屏以右侧主体和中央留白构图；竖屏使用对应横屏作参考重新生成，将主体放在右下方，并为上方额度信息留白。`picture` 根据画布宽高比选择独立的 landscape / portrait 显示资源；背景不承载数据或交互。数据字号和布局沿用已有订阅页面。

背景透明度范围 0–100%，默认 25%；0% 显示完整原图强度，100% 完全隐藏图片，松开滑块后同步到预览与副屏。空背景时禁用滑块并保留设定。有背景时取消上下栏底与边线，保留标题和左下方同步时间，不显示右上状态或右下页码。IT、动漫、龙娘分别采用冰蓝、紫藤、翡翠主题，数字及控制台强调色跟随背景；文字使用局部白色阴影增强辨识。

生成原图保留不变，页面读取 `*-screen.png?v=2`。这些显示资源按横屏 1280×720 / 竖屏 720×1280 导出，RGB 各通道对齐到间隔 8 的值（每通道最多变化 4/255），降低细微颜色噪声的编码成本，不模糊人物轮廓，也不使用全图小调色板。最终传输仍由现有流程生成完整 RGBA PNG。

生成方向：IT 为钛银芯片与冰蓝电路；动漫为短靛蓝发工程师、樱花与未来海滨；龙娘为银发、翡翠龙角与双翼、白绿服装及抽象交织结。全部为不透明图像，无文字、无界面。保留生成原文件，未裁切为竖版。

传输仍使用现有的 720×1280、alpha=255 的 RGBA PNG 流程，源背景的文件大小不等于最终设备帧大小。

## 首版验证

- Python 编译、三个修改过的 JavaScript 文件语法检查、订阅 UI 语义检查通过；现有 Python 测试 35 项通过。
- Playwright 检查四种背景 × 三个订阅页面 × 两种方向共 24 个组合，画布均未溢出，图像加载完成并使用正确方向；桌面 1440 px 与窄屏 390 px 控制台可切换四种背景，刷新后与服务状态一致。
- 24 张测试截图均按生产流程转换为 720×1280、color type 6、alpha=255 的 PNG，全部低于 1 MiB。测试数据只用于离线浏览器检查，没有写入订阅服务。
- 服务更新后恢复原来的 0° 竖屏与持续投送，选择龙娘背景；实时控制与预览同步通过。验证时实际发送帧 958157 字节、无服务错误。该结果只验证传输，尚未获得用户对新背景的实体屏目视确认。
- 只对固定背景 PNG 启用 1 小时浏览器缓存，避免逐帧重新传输源图；API 与其他响应继续 `no-store`。原图修改时须更换资源文件名或版本 URL。

本次视觉复审结论：可交付。背景保留完整人物构图，正文和额度数字可辨，控制台保持现有布局。验证截图及脚本在 `runtime/background-check/` 与 `runtime/check-backgrounds*.cjs`，不作为公开素材。

## 自动恢复投屏验证

新增生命周期测试覆盖首次启动、成功开始后保存、手动停止清除、关闭保留、旧会话取消保护、连接失败只尝试一次与手动重试，以及关闭前释放 USB。59 项 Python 测试通过。实机连续重启确认：正在投屏时重启自动产生新帧；手动停止后重启保持停止；再次开始后重启自动续投，均不需要启动脚本额外调用 Start。方向、页面、帧率和背景选项保持原值。关闭请求会在 HTTP 仍可响应渲染器时先停止输出并释放 USB，避免新旧进程争抢设备。
